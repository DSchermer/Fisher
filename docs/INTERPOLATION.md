# Interpolation between catalog openings

Generated by `extract/interpolation_error.py`. Each interior Cv point of every curve was hidden and re-estimated from the others; the table gives the absolute error as a percent of the printed value. The hidden point's neighbours are twice the printed spacing apart, so these errors overstate interpolation at the printed spacing (roughly by 4x, since the error from curvature grows with the square of the spacing).

`Config.value_at(..., interp='pchip')` and `opening_for(..., interp='pchip')` use the monotone cubic. The default stays linear: Fisher's own gas sample problem 1 (page 2-14) reaches 78% open with linear interpolation and 79% with pchip, so linear is what the catalog's worked example uses.
